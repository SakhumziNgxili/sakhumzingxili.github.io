# Transcription & Document Formatting Simulation

A practical demonstration of transcription, document cleanup, formatting and action-item extraction.

## Workflow

Audio/transcript input → accuracy review → speaker formatting → paragraph cleanup → action-item extraction → professional document output

## Demonstrated skills

- Audio-to-text transcription
- Editing machine-generated or rough transcripts
- Speaker identification and paragraph formatting
- Grammar and readability cleanup without changing meaning
- Meeting-note preparation
- Action-item extraction
- Professional document structure

## Files

- `raw-transcript.txt` — intentionally rough transcript input
- `formatted-transcript.md` — cleaned and professionally formatted transcript
- `action-items.csv` — extracted follow-up actions

All names, organisations and details in this simulation are fictional and created for portfolio demonstration purposes.
