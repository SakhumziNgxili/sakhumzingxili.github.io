# Document Management System Simulation

A practical administrative workflow demonstrating structured digital filing, naming conventions, document registers, version control and retrieval tracking.

## Workflow

Document intake → classification → naming → folder allocation → version control → register update → retrieval

## Demonstrated skills

- Digital document organisation
- File naming conventions
- Document registers
- Version control
- Metadata management
- Retrieval and status tracking
- Administrative record keeping

All records in this simulation are fictional and created for portfolio demonstration purposes.
