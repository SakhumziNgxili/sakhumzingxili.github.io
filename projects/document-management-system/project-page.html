Workflow

Tracks document ID, category, department, version, status, owner, review date, storage path and access level.

Filing Structure

Uses consistent folder paths and review rules so documents can be located quickly and maintained systematically.

Version Control

Records revisions and summarises what changed between document versions.

Retrieval & Governance

Demonstrates status, confidentiality and review metadata to support controlled document handling.
