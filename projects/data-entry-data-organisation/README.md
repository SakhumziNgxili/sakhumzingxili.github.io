# Data Entry & Data Organisation

## Project Type
Demonstration project — created to showcase professional data-entry, spreadsheet organisation and data-quality skills.

## Objective
Create and organise a realistic business dataset in a structured spreadsheet, then review the information for consistency, completeness and usability.

## Skills Demonstrated
- Accurate data capture
- Spreadsheet formatting
- Data cleaning and consistency checks
- Sorting and filtering
- Identifying missing information
- Basic data summaries
- Professional file organisation
- Attention to detail

## Dataset
The sample dataset represents fictional customer/order records for a small business. All names, contact details, order information and values are fictional and created for demonstration purposes.

## Workflow
1. Capture the sample records in a structured spreadsheet.
2. Apply consistent headings, formats and data types.
3. Check records for missing or inconsistent information.
4. Standardise entries where appropriate.
5. Use sorting and filtering to review the records.
6. Produce a short summary of the cleaned dataset.

## Quality Checks
The project focuses on checking:
- Duplicate or potentially duplicated records
- Missing customer information
- Inconsistent status values
- Inconsistent date and currency formats
- Incorrect or incomplete order fields

## Outcome
The final workbook demonstrates how raw business information can be transformed into a cleaner, easier-to-review dataset suitable for routine administrative and operational use.

## Note
This is a self-created demonstration project. It is not presented as paid client work and does not contain real customer information.
