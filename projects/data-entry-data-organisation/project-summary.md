# Data Entry & Data Organisation — Project Summary

## Overview
A self-created demonstration project showing how structured business information can be captured, checked and organised for administrative use.

## Scenario
A fictional small business needs its customer and order records organised into a consistent dataset that can be searched, filtered and reviewed easily.

## Work Completed
- Created 20 fictional customer/order records.
- Used consistent customer IDs and contact fields.
- Standardised dates to YYYY-MM-DD.
- Standardised currency values to two decimal places.
- Used controlled order and payment status values.
- Structured the data with clear column headings.
- Prepared the dataset for sorting and filtering.

## Quality Review
The records were reviewed for missing fields, inconsistent status wording, date-format differences and incomplete order information.

## Example Administrative Uses
The dataset could support routine tasks such as:
- locating customer records;
- checking order status;
- identifying pending payments;
- filtering cancelled or processing orders;
- preparing basic management summaries.

## Skills Demonstrated
Data entry · Data capture · Data cleaning · Spreadsheet organisation · Quality checking · Sorting and filtering · Attention to detail · Basic reporting

## Important Note
All records are fictional. This project is a portfolio demonstration and is not represented as paid client work.
