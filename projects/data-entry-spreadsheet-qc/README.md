# Data Entry & Spreadsheet Quality Control

A practical portfolio simulation demonstrating accurate data capture, cleaning, standardisation, duplicate detection, exception flagging, reconciliation and quality-control reporting.

## Workflow
Raw Data → Standardise → Validate → Flag Exceptions → Reconcile → Final Acceptance

## Demonstrated skills
Data entry, spreadsheet cleaning, duplicate detection, missing-data review, date and category standardisation, contact-data normalisation, quality checks, exception handling and concise QC reporting.
