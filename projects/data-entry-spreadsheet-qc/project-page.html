PORTFOLIO PROJECT

Data Entry & Spreadsheet Quality Control

A practical simulation showing how raw, inconsistent records can be transformed into a cleaner dataset with documented quality checks and exception handling.

Open Cleaned DatasetOpen README

What this demonstrates

Data Entry

Accurate capture and preservation of source records.

Cleaning

Standardised names, contact fields, dates, provinces and statuses.

Quality Control

Duplicate, missing-field and exception checks with documented flags.

Reconciliation

Record counts and acceptance status are checked before completion.

Before → After

IssueAction
Inconsistent namesTrimmed whitespace and standardised casing.
Phone formattingNormalised South African mobile number formatting.
Province abbreviationsExpanded EC/KZN to standard province names.
Status variationsStandardised active/pending/inactive values.
Duplicate candidatesFlagged records for review instead of silently deleting them.
Missing contact dataFlagged exceptions for follow-up.

QC outcome

The exercise starts with 20 source records. The QC summary documents duplicate candidates, records requiring review, formatting corrections and final acceptance.
