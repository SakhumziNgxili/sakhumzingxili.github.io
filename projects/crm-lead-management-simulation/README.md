# CRM & Lead Management Simulation

A practical CRM workflow simulation demonstrating lead capture, qualification, pipeline management, follow-up discipline and reporting.

## Workflow
Lead capture → Data quality check → Qualification → Pipeline stage → Follow-up → Outcome → Reporting

## Demonstrated skills
- CRM-style record management
- Lead qualification
- Pipeline stage tracking
- Follow-up scheduling
- Priority and next-action management
- Duplicate and missing-data checks
- Basic conversion reporting

## Files
- `lead-pipeline.csv` — working CRM-style lead register
- `pipeline-summary.csv` — management summary
- `project-page.html` — portfolio demonstration page

This is a simulated dataset created for portfolio purposes.
